A dark, atmospheric hero component featuring a full-bleed background video, glassmorphic noise overlays, and `framer-motion` staggered text pull-up effects.

## Features
- Full-bleed background HTML5 video with gradient and noise overlays
- Elegant staggered text pull-up animations via `framer-motion`
- Hover-interactive translucent navigation bar
- Built with Tailwind CSS v4 and standard `shadcn/ui` folder structure inside `src/components/ui/`
- SSR-safe component composition
