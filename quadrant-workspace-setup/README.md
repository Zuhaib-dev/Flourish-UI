A premium, highly polished workspace setup and configuration modal. It features a stunning split-layout design with a picturesque background, meticulous form elements, and smooth interactions.

**Author**: Zuhaib Rashid Dev and adventrer github/zuhaib-dev

## 🌟 Overview

The **Quadrant Workspace Setup** UI captures the aesthetic of modern, high-end SaaS onboarding flows. The split-layout seamlessly separates progress tracking from configuration tasks, maintaining an elegant look and feel throughout.

## ✨ Features

- **Split Modal Layout**: Clean separation of setup steps (left) and interactive form content (right).
- **Premium Background**: A soft, artistic background image adds an organic touch, muted by a slight glassmorphism blur overlay.
- **Micro-interactions**: Beautiful chip tags, toggle switches, and model selector grids built with custom CSS.
- **Pixel-Perfect Styling**: Detailed typography and perfectly spaced elements that scale well on desktop.

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS v4
- Framer Motion
- Lucide React (Icons)
