A high-fidelity, 3-column workspace dashboard designed for podcast and content studios. It features an intricate collapsible sidebar, a central AI-assisted content creation feed, and a rich media transcript view.

**Author**: Zuhaib Rashid Dev and adventrer github/zuhaib-dev

## 🌟 Overview

The **Proma Content Workspace** demonstrates how to build a complex, multi-pane SaaS application. It perfectly balances a dense information architecture with a clean, airy light-mode aesthetic.

## ✨ Features

- **3-Column Architecture**: Seamlessly integrates a sidebar nav, a central work area, and a contextual right-panel (Transcript/Clips).
- **AI Content Feed**: The central column renders complex conversational UI, including stacked attachment cards, thinking states, and interactive grid action cards.
- **Rich Media Transcript**: The right panel features a video player thumbnail and a perfectly styled speaker transcript feed.
- **Ultra-Premium Polish**: Custom scrollbars, staggered Framer Motion entrance animations, and deeply thought-out typography and hover states.

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS v4
- Framer Motion
- Lucide React (Icons)
