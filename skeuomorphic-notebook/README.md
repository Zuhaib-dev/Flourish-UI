# Skeuomorphic Notebook Guestbook 📓

A playful, highly interactive skeuomorphic take on a digital guestbook. It brings the tactile feel of a physical leather-bound journal into the browser with realistic page flips, handwritten typography, and organic ink features.

## Features

- **Realistic Book Physics**: Built with Framer Motion to simulate 3D page flips, realistic page curling, and dynamic stacked paper depth.
- **Skeuomorphic Aesthetic**: Intricate details like a leather book wrapper, brass corners, velvet bookmark, and authentic paper textures.
- **Interactive Signature Canvas**: Leave a note using `react-signature-canvas` with selectable ink colors (Sepia Russet, Moss Green, Terracotta, Vintage Ink).
- **Rich Archival Experience**: Integrated playable ambient audio UI, floating search pill, interactive sticky notes, and Polaroid photo mounts.
- **Custom Wax Seal Animation**: Complete the guestbook entry with a satisfying interactive wax seal button.

## Tech Stack
- React 19 / Next.js 15 (App Router)
- Tailwind CSS (v4)
- Framer Motion
- React Signature Canvas
- Lucide React

## Running Locally

```bash
pnpm install
pnpm dev
```
