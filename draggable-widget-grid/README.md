# Draggable Widget Grid

A beautiful, draggable grid of widgets that can be rearranged seamlessly using `motion/react`.

## Features
- **Draggable Tiles**: Drag and rearrange any widget in a grid format.
- **Responsive Layout**: Exact tiler turns the sequence into a gap-free rectangle at any column count.
- **Accessibility & Input Agnostic**: Supports mouse and pen (immediate drag). Touch (long press). Keyboard (Alt + arrow keys).
- **Dark & Light Mode**: Adheres strictly to native generic theme tokens like `bg-card`, `ring-border`, `text-foreground`.
- **Motion Powered**: Gracefully animated on enter, exit, and drag operations using `motion`.
