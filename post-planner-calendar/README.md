A pristine, minimalist SaaS dashboard component designed for planning and organizing content posts. Features a comprehensive calendar grid and data summary cards with a clean light-mode aesthetic.

## 🌟 Overview

The **Post Planner Calendar** is a highly detailed, pixel-perfect recreation of a modern content management dashboard. It focuses on clarity, utilizing subtle off-white backgrounds, precise typography, and color-coded categorizations to manage complex scheduling data.

## ✨ Features

- **Clean Light-Mode Aesthetic**: Uses a calming `#f8f9fb` background, crisp white cards, and perfectly contrasting text for ultimate readability.
- **Data Summary Cards**: 
  - **Slots Filled**: Features a multi-color segmented progress bar mapping directly to content statuses (Posted, Ready, Draft, Idea).
  - **Open Slots**: A clean, interactive list of upcoming content needs with specific category tags.
- **Interactive Calendar Grid**: A beautifully structured 7-column calendar that seamlessly houses complex nested data, including multi-line text snippets, draft badges, and colored category indicators (`rings` and `dots`).
- **Pillar Categorization**: A horizontal taxonomy row showing the distribution of content pillars (Visual, Educational, Business, Personal).

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS v4
- Lucide React (Icons)
