A highly interactive and animated crowd rendering component using HTML5 Canvas and `gsap` (GreenSock Animation Platform).

## Features
- **Generative GSAP Canvas**: Draws custom sprites walking in random animated paths simulating a lively crowd on a 2D Stage.
- **Performant & Lightweight**: No heavy CSS DOM manipulation. Done entirely through requestAnimationFrame tied closely with GSAP scaling on a `<canvas>` element.
- **Configurable Grid**: Modify the sprite rows, columns, and image asset source via flexible component properties out of the box.
