A high-fidelity, interactive hover layout component designed for editorial portfolios and creative agencies. 

It splits the view into an interactive list on the left and a sticky, cross-fading preview pane on the right. Powered by Framer Motion, it features fluid magnetic background highlighting and buttery smooth layout animations.

## Features
- **Magnetic Active States**: A fluid background shape seamlessly follows the user's cursor or focus across list items.
- **Crossfading Previews**: The preview pane beautifully animates the entrance and exit of images, titles, and descriptions.
- **Responsive Layout**: Designed to work beautifully on both desktop grids and mobile devices.

## Tech Stack
- React / Next.js
- Tailwind CSS
- Framer Motion
