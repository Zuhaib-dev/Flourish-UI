# Daybreak Editorial

A premium, interactive Neo-Classical design system and UI shell for long-form narrative, reading, and writing experiences. Built with Next.js 15, Tailwind CSS v4, and Framer Motion.

## Features

- **Interactive Layout**: Expandable/collapsible toolbars, sidebars, and dialogue modals powered by Framer Motion spring physics.
- **Neo-Classical Aesthetic**: Custom tailored typography setup (`Newsreader` and `Plus Jakarta Sans`) mapped to semantic variables for a high-end literary feel.
- **Crisp SVG Icons**: Powered by `lucide-react` for perfect scaling.
- **Glassmorphism & Shadows**: Sophisticated usage of backdrop filters and ambient drop shadows to create a layered "floating" interface over the manuscript.

## Quick Start

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack
- React 19 + Next.js 15 (App Router)
- Tailwind CSS v4
- Framer Motion
- Lucide React
