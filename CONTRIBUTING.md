# Contributing to Flourish UI ✨

First off, thank you for considering contributing to Flourish UI! It's people like you that make Flourish UI such a great library.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for Flourish UI. Following these guidelines helps maintainers understand your report, reproduce the behavior, and find related reports.

- **Check existing issues:** Make sure the bug wasn't already reported.
- **Provide detailed steps:** Explain exactly how to reproduce the bug.
- **Provide context:** What environment are you running in? (e.g., Next.js version, React version, browser).

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion.

- **Use a clear and descriptive title** for the issue.
- **Provide a step-by-step description** of the suggested enhancement.
- **Explain why this enhancement would be useful** to most users.

### Pull Requests
- **Create a feature branch:** Branch off from `main` (e.g., `feature/amazing-new-component`).
- **Follow the codebase style:** We use Tailwind CSS v4 syntax, Framer Motion, and strict TypeScript.
- **Commit messages:** Write clear, concise commit messages following the Conventional Commits specification.
- **Include previews:** If you are adding a new component, please include a `Preview.png` in its `public` folder and update the `README.md` files accordingly.

## Project Structure
Each component lives in its own standalone directory (e.g., `bloom-select/`) containing a Next.js setup with Tailwind and Framer Motion. This ensures each component is isolated, easily previewable, and has its own dependencies mapped out.

## Questions?
If you have questions about how to use the library or how to contribute, feel free to open an issue or reach out via Twitter.

Happy flourishing! 🌸
