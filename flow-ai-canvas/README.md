An ultra-premium node-based visual workflow editor interface. Built with an intricate left sidebar, an interactive node library panel, and a beautifully designed dot-grid canvas with floating toolbars and a minimap.

**Author**: Zuhaib Rashid Dev and adventrer github/zuhaib-dev

## 🌟 Overview

The **FlowAI Canvas** perfectly captures the aesthetic of modern node-based automation platforms (like Zapier, Make, or n8n) but with an ultra-premium, AI-first design language. 

## ✨ Features

- **Infinite Dot Grid**: A perfectly styled CSS-only dot grid background.
- **Node Architecture**: Highly polished node blocks with perfectly aligned input/output connection points.
- **Floating Panels**: An intricate collapsible "Node Library" search panel floating directly on the canvas.
- **Workflow Tools**: Beautiful floating zoom/pan controls and a minimap representation in the corners.
- **Pixel-Perfect Spacing**: Every border, shadow, and font size is meticulously crafted.

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS v4
- Framer Motion
- Lucide React (Icons)
