# Isometric Dashboard 📊

A premium, high-fidelity dark-mode dashboard component featuring a true 3D isometric stacked bar chart and a highly detailed interactive heatmap calendar. 

Built completely with CSS 3D transforms and React—no canvas or WebGL required.

## Features

- **True 3D Isometric Chart**: A complex multi-row stacked bar chart rendered entirely in the DOM using `preserve-3d` and precise CSS rotations (`rotateX`, `rotateZ`).
- **Interactive Floating Tooltips**: Framer Motion powered tooltips that seamlessly track your mouse across the isometric 3D planes to display exact metrics.
- **Heatmap Calendar UI**: A beautiful date range picker UI with a multi-state heatmap calendar grid, pill-shaped segmented controls, and animated toggles.
- **Glassmorphic Dark Aesthetic**: Deep `#121212` backgrounds with `#1f1f1f` cards, subtle atmospheric lighting blur effects, and vibrant chart colors.

## Tech Stack
- React 19 / Next.js 15 (App Router)
- Tailwind CSS (v4)
- Framer Motion
- Lucide React

## Running Locally

```bash
pnpm install
pnpm dev
```
