A GitHub-style contribution heat map that seamlessly transforms into an isometric 3D skyline. Every day is a box on a grid, smoothly transitioning between a 2D overhead view and a 3D perspective using HTML5 Canvas.

## Features
- Hardware-accelerated HTML5 Canvas rendering for massive grids
- Smooth 2D-to-3D morphing transition via custom camera maths
- Interactive tooltips, keyboard navigation, and click handlers
- Six built-in color palettes (`github`, `ocean`, `halloween`, `ember`, `grape`, `mono`) with light and dark mode support
- Fully isolated component with zero external dependencies (React only)
