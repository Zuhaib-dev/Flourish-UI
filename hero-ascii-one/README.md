A dark, cyber-themed animated hero component featuring Unicorn Studio background rendering and typing aesthetics.

## Features
- Fully integrated with Unicorn Studio for rich canvas animations
- Built with standard Tailwind CSS v4 syntax
- Highly responsive, with specific mobile-friendly starry backgrounds
- Implements `shadcn/ui` folder structure inside `components/ui/`
- Zero hydration mismatch: specifically configured for Next.js 14+ SSR environments
