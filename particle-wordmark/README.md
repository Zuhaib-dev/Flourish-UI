A gorgeous, interactive particle-based wordmark component.

## Features
- **Generative Particles**: Rendered entirely through HTML5 Canvas mathematics without relying on heavy external assets.
- **Customizable**: Allows tweaking mode, hue, saturation, and brightness out of the box.
- **IFrame Isolation**: Safely sandboxed so complex styles and document assumptions don't leak into the host page.
