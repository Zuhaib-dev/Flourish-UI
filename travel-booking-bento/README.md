A beautiful, highly complex travel booking dashboard featuring a modern bento-box grid layout, glassmorphism overlays, and stunning typography.

**Author:** [Zuhaib Rashid](https://www.zuhaibrashid.com)

## 🌟 Overview

The **Travel Booking Bento** UI captures the aesthetic of modern, high-end travel platforms. The bento-box layout seamlessly organizes destinations, search inputs, and immersive imagery in an engaging format.

## ✨ Features

- **Bento Grid Layout**: Complex CSS flex/grid structures to perfectly match modern asymmetrical dashboard styling.
- **Glassmorphism Overlays**: Stunning image masking and dark gradient overlays to make typography pop over photos.
- **Premium Typography**: Built with **Plus Jakarta Sans** and **Inter** from Google Fonts for that ultra-modern look.
- **Micro-interactions**: Beautiful chip tags, search inputs, avatar clusters, and subtle hover animations on the main cards.

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS v4
- Lucide React (Icons)
