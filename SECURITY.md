# Security Policy

## Supported Versions

Currently, the following components and versions are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Flourish UI. If you discover a security vulnerability within Flourish UI, please send an e-mail to Zuhaib Rashid via [zuhaib.dev@example.com](mailto:zuhaib.dev@example.com) (or contact via Twitter @ZuhaibRashid).

Please do not report security vulnerabilities through public GitHub issues. 

All security vulnerabilities will be promptly addressed.

When reporting a vulnerability, please include the following information:

* The type of vulnerability (e.g., XSS, CSRF, etc.)
* The component(s) affected
* Step-by-step instructions to reproduce the vulnerability
* Any potential impact it may cause

Thank you for helping keep Flourish UI secure for everyone.
