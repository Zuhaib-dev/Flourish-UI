A pristine, high-fidelity chat interface designed for interacting with specialized AI agents (like an SEO Specialist). It features a full-width viewport design with a collapsible sidebar and a central chat feed capable of rendering complex, interactive data cards.

## 🌟 Overview

The **SEO Agent Chat UI** demonstrates how to build a state-of-the-art copilot interface. It moves beyond simple text chat by allowing the AI to respond with rich, interactive UI components such as Performance Snapshots and Budget Allocation tables.

## ✨ Features

- **Rich Agent Responses**: The chat feed supports complex blocks like nested data grids, pill lists, and action buttons, mirroring advanced SaaS workflow tools.
- **Subtle, Premium Styling**: Uses a `#f9fafb` backdrop with a white, slightly rounded main chat container, giving the interface a floating, lightweight feel.
- **Framer Motion Integration**: Features staggered entrance animations for both the navigation menu items and the conversational feed.
- **Intricate Sidebar**: A fully built-out navigation pane featuring categorized agent lists, pulsing status dots, and a floating profile footer.

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS v4
- Framer Motion
- Lucide React (Icons)
