# Digital Signature Modal ✍️

A premium, highly interactive, and functionally complete React component for capturing digital signatures in web applications. It provides a polished and legally compliant-looking interface for users to sign documents.

## Features

- **Draw**: A real-time, interactive HTML5 canvas powered by `react-signature-canvas` allowing users to physically draw their signature. Includes ink color selection (Obsidian Black, Executive Navy) and canvas clearing logic.
- **Type**: Real-time signature generation based on user input. It automatically computes initials and dynamically updates beautiful authentic handwriting fonts (`Caveat` and `Dancing Script`).
- **Upload**: A sleek image upload interface that accepts scanned signatures and displays them with a seamless preview.
- **Fluid Animations**: Handcrafted micro-interactions, layout shifts, tab transitions, and an impressive pre-drawn signature loading animation using `framer-motion`.
- **Premium UI**: Glassmorphism styling, ambient blurred orbs, deep shadow layers, and custom-styled checkboxes to give an enterprise-tier aesthetic.
- **Zero Layout Shift**: Designed entirely with `lucide-react` inline SVGs to prevent any FOUC or icon shifting.

## Tech Stack
- React 19 / Next.js 16
- Tailwind CSS (v4)
- Framer Motion
- React Signature Canvas
- Lucide React
- Next/Font (Outfit, Caveat, Dancing Script)

## Running Locally

```bash
pnpm install
pnpm dev
```
